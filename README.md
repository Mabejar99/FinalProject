In the folder SynthSOD_bleeding_sim, you can find the code used to generate the database. This module combines two existing datasets and stores the source information in a JSON file. It also includes all the spatialization code, as well as a reorganization script used to obtain the final database containing the spatialized outputs.

The folder HDemucs_ExpSpheres contains all the training code, including the original Demucs implementation, as well as the experimental setup used for training and the scripts for validating the results.

The folder REAPER includes the script that enables the interface between Demucs and Reaper through BlackHole.

The .gitignore file specifies the files that are excluded from version control due to their large size, such as training logs and checkpoints.
